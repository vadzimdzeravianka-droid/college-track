### Authentication
- Invalid passkey shows error message (tested in auth.spec.ts)
- Direct route access without auth redirects to /login (tested in auth.spec.ts)
- Session persists across page refreshes (validated in persistence tests)

### Form Validation
- Multi-step form navigation (back/forward buttons work)
- Required field validation prevents submission
- Date picker interactions work correctly
- Select dropdown interactions work correctly

### State Management
- Auto-status progression when all checklist items complete
- Status reverts when items unchecked
- Urgency color updates based on deadline
- Data persists in database (page refresh test)

- Each test completes within 30 seconds

- Retry flaky tests automatically (Playwright config)

- WebKit (Safari, enabled in config)
